# AVANCE PF 02 - SPEEDMAX

## Descripción del Proyecto
Proyecto web multipágina desarrollado para el curso **Taller de Programación Web**. El sitio simula la plataforma comercial de "Speedmax", un proveedor de internet por fibra óptica. El proyecto ha sido diseñado cumpliendo estrictamente con estándares modernos de desarrollo *Front-End*, priorizando la accesibilidad, el diseño responsivo (*Mobile-First*) y la interactividad sin depender de frameworks externos.

## Cumplimiento de la Rúbrica
Este proyecto abarca los 5 pilares de evaluación:
1. **Estructura HTML5:** Uso riguroso de etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) e integración de atributos ARIA para accesibilidad.
2. **Estilos CSS3 (Vanilla):** Diseño 100% responsivo utilizando CSS Grid y Flexbox. Se implementaron variables de entorno (`:root`) para mantener la cohesión de la paleta de colores y una tipografía optimizada con interletraje.
3. **JavaScript Interactivo:** Scripts modulares que incluyen detección automática de navegación, efectos de scroll dinámicos en el header, acordeones interactivos para Preguntas Frecuentes y validación nativa de formularios con redirección de éxito.
4. **Experiencia de Usuario (UX):** Interfaz en *Dark Mode* con contrastes altos en color cian (`#00f0ff`), *feedback* visual inmediato en botones y formularios, y navegación clara e intuitiva.
5. **Documentación:** Código limpio, indentado y comentado en sus tres capas (HTML, CSS, JS).

## Estructura de Archivos
* `index.html`: Página de inicio (Hero section, estadísticas y enlaces rápidos).
* `novedades.html`: Tablón oficial de comunicados y expansión de la red.
* `beneficios.html`: Detalles técnicos del servicio con testimonios de usuarios.
* `faq.html`: Centro de ayuda con menú tipo acordeón interactivo.
* `contacto.html`: Formulario de validación de cobertura con validación JS en el cliente.
* `styles.css`: Hoja de estilos global.
* `script.js`: Lógica de interactividad y validaciones.

## Instrucciones de Uso
1. Descargue o clone este repositorio en su entorno local.
2. Asegúrese de que los 7 archivos (5 HTML, 1 CSS, 1 JS) se encuentren en la misma carpeta o directorio raíz.
3. Abra el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Safari, Edge).
4. No requiere instalación de dependencias, Node.js, ni servidores locales para funcionar.
